# Add Torznab API Integration for Sonarr/Radarr

## Overview
This PR adds a Torznab-compatible API to PlexRipper, allowing it to function as an indexer for Sonarr and Radarr. This enhancement enables users to utilize their Plex servers as content sources, skipping public and private trackers when content is already available on a Plex server.

## New Features

### 1. Torznab API Endpoints
- Added `/torznab` endpoint for search requests from Sonarr/Radarr
- Implemented `/api/download` endpoint to trigger downloads
- Created XML formatting compatible with the Torznab specification

### 2. Multi-Server Search Support
- Search across all available Plex servers (enabled by default)
- Option to limit searches to specific servers through settings
- Server filtering implemented in search queries

### 3. Configuration Options
- Configurable API key for security
- Settings for controlling which servers to include in searches
- Download directory configuration for Sonarr/Radarr monitoring

### 4. Integration with Existing System
- Utilizes PlexRipper's existing download framework
- Compatible with the existing database and entity models
- Leverages the established authentication mechanisms

## How It Works

1. When Sonarr or Radarr searches for content, they send a request to PlexRipper's Torznab endpoint
2. PlexRipper searches through connected Plex servers for matching content
3. Results are returned in Torznab-compatible format
4. When Sonarr/Radarr selects content for download, PlexRipper handles fetching it from the source Plex server
5. The content is saved to a configured directory where Sonarr/Radarr can import it

## User Benefits

- **Bandwidth Efficiency**: Avoid re-downloading content from the internet when it's already available on another Plex server
- **Integration with Automation**: Works seamlessly with existing Sonarr/Radarr workflows
- **Cross-Server Content Sharing**: Simplifies keeping multiple Plex servers in sync

## Technical Implementation

- Added new settings modules for Torznab configuration
- Implemented Torznab XML response formatting
- Added server filtering based on settings
- Integrated with existing download task generation

## Testing

The implementation has been tested with:
- Local PlexRipper instance
- Multiple connected Plex servers
- Sonarr and Radarr as clients
- Various media types (movies, TV shows)

## Documentation

Usage instructions for end users:

1. Enable the Torznab integration in PlexRipper settings
2. Configure the API key (auto-generated by default)
3. Add a new Torznab indexer in Sonarr/Radarr pointing to the PlexRipper instance
4. Start using Sonarr/Radarr normally - content will be downloaded from Plex when available
